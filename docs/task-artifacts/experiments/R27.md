## 核心观测

1. **单变量破坏面小于预期——静态页面产物完整保留**：`crawlLinks:false` 关闭 crawler 爬链后，3 个显式种子页（`/`、`/guide/baseline`、`/guide/failure-domains`）仍全量预渲染（html = 3），冒烟字节级核对为静态产物命中（非 SSR 兜底）；仅 content API 路由缺席（`api/_content` 不存在）。
2. **crawler 关闭后 content cache/search 路由未入初始路由列表**：content 的 `cache.<ts>.json` / `search-<ts>` 未出现在初始路由列表（基线/R28 语境 content v2.13.9 在 `nitro:config` 阶段 unshift 注册）——注册条件疑似依赖 crawlLinks 态，详见 [FINDINGS #18](./FINDINGS.md)。
3. **F47 签名不变**：`cache.json` 200+404shell，与基线/R28 一致——F47 独立于 prerender 变量。
