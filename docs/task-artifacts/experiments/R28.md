## 核心观测

1. **预期"全清 → 0 routes"未出现——nitropack `/` 回填兜底（源码行号实锤）**：`routes.size === 0 && crawlLinks === true` 时 nitropack@2.13.4 自动回填 `/` 种子（core/index.mjs:1987-1992）→ 实际 1 initial route，crawler 从 `/` 只爬出 4 条资源路由（payload/ipx/i18n），合计 Prerendered 5 routes（基线 11）。
2. **html 仅剩 index.html，Content 结构化索引不在构建期产物**：html 清单从基线多页收敛至仅 index.html（11 → 1）；`api/_content` 不存在（与基线一致）。
3. **运行时三断言全靠 SSR 兜底，F47 签名不变**：冒烟先验 `Listening` 行 ✓ 后，`/` 与 `/guide/baseline` 均 200 但为 SSR 兜底渲染（非预渲染产物命中）；`cache.json` 200+404shell——[F47](../failure-catalog.md) 基线签名不变。
4. **破坏面被回填收窄——完整触发需 R27+R28 叠加（R29 设计动机）**：单变量 `routes.clear()` 因回填机制未达"全清"终态；R29（`crawlLinks:false` + `routes.clear()` 同开）关闭 crawlLinks 后回填不触发，为完整触发路径。
