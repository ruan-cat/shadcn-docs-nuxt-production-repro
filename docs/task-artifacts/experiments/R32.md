> 本实验原于 2026-10-28 被合并进 R31-family（「单一 mermaid 触发块覆盖 R30/R32/R33」），该合并所依赖的前提——**「`debug` 是 `mermaid@11.17.2` 的传递依赖」**——**经复核证伪**：
>
> - `pnpm-lock.yaml` 的 `mermaid@11.17.2` 依赖块（line 12908–12931）共 22 项依赖，**无 `debug`**；
> - 安装态 `mermaid@11.17.2` 的 `package.json` `dependencies` **无 `debug`**；
> - `shadcn-docs-nuxt@1.1.9` 依赖块（line 14580–14603）**未直接声明 `debug`**；
> - `debug@4.4.3` 实际来自**构建工具链**（`@babel/core` / `@nuxt/cli` 等），与 mermaid 无关。
>
> → **`debug` 不在客户端依赖图内，mermaid 触发块根本触达不到它** → R31-family **不覆盖 R32**，本实验**回到未启动池**（[QUEUE.md](./QUEUE.md) 表 4）。
