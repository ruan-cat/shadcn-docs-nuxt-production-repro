## 核心观测

1. **R14 信号零复现**：全日志无 `Cannot find package 'ufo'`，prerender 正常完成；R14 时代的 unresolved-as-external 警告族（@shikijs/*、@intlify/h3、remark-emoji）未出现。
2. **ufo 打包形态**：nitro 核心本就把 ufo vendored 进 `chunks/_/nitro.mjs`（parseURL/getQuery 等内联实现，无外链 import）；`inline: ["ufo"]` 近乎空操作；`.output/server/node_modules/ufo/` 仍存在 trace 复制的外部拷贝（供 vue-bundle-renderer 运行时 import）——inline 声明未覆盖 trace-shaker 的外部依赖闭包。
3. **宽度轴对照结论**：R14 blanket `inline:[/.*/]` 的确定性失败（`Cannot find package 'ufo'` @ prerender 初始化）不能归因于 ufo 本身，而是 blanket 把 @shikijs/*、@intlify/h3、remark-emoji 等**无法内联的 CJS/子路径依赖**强行拉进 inline 集合所致；R13 精确单包对照成功隔离故障源——R14 类故障的根治方向不在 inline 宽度调参，而在 unresolved-as-external 解析层（本轮 main 基线仅存的同族低烈度表现：cache-driver.js "could not be resolved – treating it as external" 警告）。
