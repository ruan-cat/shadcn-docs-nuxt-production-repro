# 指南

本栏目收录当前控制组的基线事实与故障域划分，供后续单变量实验对照。

- [绿色控制组](/guide/baseline) —— 精确固定的依赖版本与控制组口径。
- [故障域](/guide/failure-domains) —— 已确认的故障边界与复现矩阵。

> 这个页面本身是 **F47 第三层修复**的附带产物：上游 layer 的侧边栏会链接栏目根路径
> `/guide`，而在 200 掩码存在时该链接返回「200 + HTML 404 shell」，看起来一直「正常」。
> 掩码移除后 crawler 立刻发现它是真死链 → 预渲染失败。根因是栏目缺少落地页，
> 这里补上落地页，而不是放宽 `prerender.failOnError`。
